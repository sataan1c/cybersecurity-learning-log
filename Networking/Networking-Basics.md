What is network?

Network is couple of devices or big networks connected to each other. Two connected laptops or a lot of local networks connected to each other can be network.



Network devices
Network devices is all hardware devices including pc, laptops, phones or routers are connected between themselves.

Device - laptop or phone we use

Switch - network device we use to connect a lot of devices

Router - network device we need to use for connections between devices and to direct the traffic to other networks

Network interface/Network adapter - physical device inside laptops and pc's that identify device in network



Types of connection

LAN - Local Area Network. For example devices connected at our home

WAN - Wide Area Network. A lot of LAN networks connected to each other through city's also.



How information travels through the network?
For example we have a laptop and we want to call our friend who is in another country. So we call him with video. What happens and how we can talk? First of all our laptop connected to our router. Laptop starts sending ARP requests. When router gets it and send a response it writes in table where router keeps destination MAC addresses. Laptop has a network adapter inside with MAC address. It sends frames to the router. Frame is a little part of packet. Frame includes sender MAC address and destination MAC address. MAC address is a physical number of a devices network adapter that identify the device in network. Also it includes sender IP address and destination IP address, time and data. Router gets this frames and when it is ready to send it to another network we went out of out LAN network. Router starts sending to my friends router these packets
